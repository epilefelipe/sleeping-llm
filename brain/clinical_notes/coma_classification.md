# Clinical Disorders of Consciousness (DoC) 🏥

Medical classification of altered states of consciousness, providing the biological targets that **Project Sleeping LLM** models *in-silico*.

---

## 1. Spectrum of Disorders of Consciousness

| State | Wakefulness (Eye-opening) | Awareness (Self & Environment) | Communication | Motor Response |
| :--- | :---: | :---: | :---: | :---: |
| **Coma** | ❌ None | ❌ None | ❌ None | Reflexive / Posturing only |
| **Vegetative State / UWS** | ✅ Preserved (Sleep-wake cycles) | ❌ None detectable | ❌ None | Involuntary reflexes |
| **Minimally Conscious State (MCS-)** | ✅ Preserved | 🟡 Inconsistent but reproducible | ❌ None | Visual tracking, localization to noxious stimuli |
| **Minimally Conscious State (MCS+)** | ✅ Preserved | 🟢 Command following, intelligible verbalization | 🟡 Inconsistent | Intentional communication attempts |
| **Locked-in Syndrome (LIS)** | ✅ Preserved | ✅ Full awareness | 🟡 Vertical eye movements / blinks | Quadriplegia & anarthria |
| **Cognitive Motor Dissociation (CMD)** | ✅ Preserved | ✅ Covert awareness on EEG/fMRI | ❌ Motor paralysis | Intentional brain oscillations to commands |

## 2. The Core Enigma: Spontaneous vs. Failed Emergence

* **Why do some patients awaken while others remain in chronic UWS?**
  * Both groups may exhibit similar anatomical lesions on structural CT/MRI.
  * The difference lies in **functional dynamical integration**: whether the thalamocortical loops and frontoparietal networks can spontaneously re-establish global informational criticality and high perturbational complexity ($\text{PCI} > 0.31$).
* **Project Sleeping LLM Thesis:**
  * By reproducing these exact functional breakdowns in Transformers, we can identify which non-linear intervention parameters flip a stalled network back across the critical threshold into self-sustaining ignition.

1. **Onboarding Researchers:** Any new computational neuroscientist, ML engineer, or neurologist joining the project can read this folder to get immediately up to speed.
2. **The Signal Paradigm:** Establishes the foundational principle that coma in deep networks must be diagnosed and reawakened in the **Signal Domain (voltages/activations)**, not through natural language text.
3. **The LavaRand / Chaotic Entropy Principle:** Explains why algorithmic pseudorandomness fails to break coma attractors, and why true physical entropy (chaotic fluid dynamics / thermal noise) is required for non-seizure re-ignition.
4. **Boundary Conditions (Theoretical Prudence):** Clarifies that we do not write arbitrary code until we have strict mathematical limits on what constitutes a valid "coma" versus irreversible system destruction.

## 🎯 Purpose of this Knowledge Base

1. **Onboarding Researchers:** Any new computational neuroscientist, ML engineer, or neurologist joining the project can read this folder to get immediately up to speed.
2. **Grant & Paper Drafting:** Centralized references, quotes, and mathematical formulas for upcoming grant applications (Templeton, ARPA-H, ANID).
3. **Traceability:** Recording how theoretical questions (e.g., residual stream damping vs. thalamocortical severance) are answered by literature.
